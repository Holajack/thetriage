Before generating, reference these existing assets for style consistency:
- `assets/trail-buddies/bear-frames/bear_frame_00.png` — chunky pixel bear, ~200x200, transparent BG
- `assets/trail-buddies/fox-frames/fox_frame_00.png` — pixel fox, orange-red/cream
- `assets/Background_animations/Forest/rocky_mountain.png` — pixel landscape, layered
- `assets/Background_animations/Forest/evergreen_tree.png` — pixel tree, transparent BG

**Core style rules:** Retro 16-bit pixel art, chunky visible pixels, no anti-aliasing, transparent PNG backgrounds, warm saturated palettes, cute/chibi proportions.
