## 1. Product Overview

### What Is HikeWise?

HikeWise is a smart study tracking app for students. It transforms study habits through intelligent focus sessions, friendly competition, and an AI companion that keeps students on track.

### Core Tagline

**"Study smarter, not harder with HikeWise"**

### Status

- Pre-release — currently accepting waitlist signups at hikewise.app
- Launching on **iOS and Android**
- Website is live with 64 published blog articles and full SEO infrastructure

### 4 Core Features

1. **Focus Sessions** — Three scientifically-designed study modes:
   - Balanced (25/5 min), Sprint (15/3 min), Deep Work (50/10 min)
   - Maximizes retention, minimizes burnout
   - Custom timer options

2. **Study Rooms** — Virtual co-working spaces:
   - Private or public rooms
   - Real-time friend presence
   - Ambient background sounds
   - In-room chat and reactions

3. **Progress Tracking & Analytics** — Beautiful dashboards:
   - Daily, weekly, monthly stats
   - Streak tracking and milestones
   - Subject-wise breakdowns
   - Exportable study reports

4. **Leaderboards & Competition** — Gamified motivation:
   - Friend and global rankings
   - Weekly competitions
   - Achievements and badges
   - Seasonal challenges

### AI Companion: Nora

- **Name:** Nora
- **Role:** Personal AI study coach, available 24/7
- **Capabilities:** Personalized study recommendations, smart reminders, answers questions, explains concepts, adaptive learning support
- **Mascot images:** Available at hikewise.app (nora-ai.png, nora-mascot.png)

### Key Differentiators

- AI companion (Nora) that adapts to individual study patterns
- Virtual study rooms for social accountability
- Gamified leaderboards that make studying competitive and fun
- Evidence-based focus session modes backed by learning science

### 8.2 Complete Screen Guide

Below is every screen in the app, grouped by flow. For video demos, marketing screenshots, or content creation, this describes exactly what the user sees and does on each screen.

#### Landing & Authentication

**Landing Page**

- What users see: Animated HikeWise logo fading in, tagline text, two buttons ("Sign In" and "Sign Up")
- What happens: Authenticated users with recent sessions skip straight to the main app; new or logged-out users pick sign-in or sign-up
- Visual style: Clean entry screen with brand colors, scale and fade animations on the logo

**Login Screen**

- What users see: Email input, password field with show/hide toggle, "Forgot Password?" link, "Sign Up" redirect
- What happens: Clerk authenticates credentials; on success, routes to main app (or onboarding if first time)
- Details: Error messages display with a shake animation; loading spinner during auth

**Forgot Password / Reset Password**

- What users see: Email input to request reset code, then a screen to enter the code + new password
- What happens: Clerk sends a password reset email, user enters the code and sets a new password

**Email Verification**

- What users see: Their email displayed, a code input field, and a "Resend Code" button
- What happens: After signing up, Clerk sends a verification code to their email; entering it activates the account

**Two-Factor Verification**

- What users see: 2FA code input field
- What happens: If 2FA is enabled on the account, this step verifies the second factor before granting access

---

#### Onboarding (First-Time Users)

New users go through a 6-step onboarding flow after account creation. Each screen shows progress dots at the bottom.

**Step 1 — Account Creation**

- What users see: Form with full name, username, email, password, and confirm password fields. Progress indicator shows "Step 1 of 5"
- What happens: Creates the Clerk account, triggers email verification
- Details: Real-time validation with visual feedback (green checkmarks, red warnings)

**Step 2 — Profile Creation**

- What users see: Profile photo picker (camera or gallery), bio field (180 chars max), university name, location, and current classes inputs
- What happens: Saves profile to Convex database; profile photo is compressed before upload
- Details: Nora character appears as a guide introducing herself

**Step 3 — Trail Buddy Selection**

- What users see: Horizontal carousel of 6 animated animal companions — Fox, Bear, Deer, Nora (dog), Wolf, and Lion — each with a walking animation (28-frame spritesheet)
- What happens: User swipes through buddies, selects one, and can give it a custom name
- Details: Each buddy has a unique color identity and personality description; Lion is marked as Elite-exclusive

**Step 4 — Focus Sound & Method Setup**

- What users see: Focus method options (Balanced 45/15, Sprint 25/5, Deep Work 90/5), study sound options (Lo-Fi, Nature, Classical, Jazz, Ambient), and environment theme options (Home, Office, Library, Coffee, Park)
- What happens: Sets the user's default study session preferences
- Details: Music preview plays when tapped; collapsible sections with Nora guide bubbles

**Step 5 — Privacy Settings**

- What users see: 11 toggle switches organized into 4 groups — Profile & Visibility (3), Study Activity (3), Communication (3), Data & Analytics (2)
- What happens: Configures privacy preferences (public profile, leaderboard visibility, DMs, etc.)
- Details: Most default to ON; Study Session Visibility and Location Sharing default to OFF

**Step 6 — App Summary**

- What users see: Feature highlights with icons — Focus Sessions (timer icon), Nora AI Tutor (chat bubbles), Study Rooms (people icon), Progress & Streaks (analytics icon). Nora speech bubble welcomes them
- What happens: Pressing "Start My Journey" marks onboarding complete and navigates to the main app
- Details: Optional interactive walkthrough can begin on the Home Screen after this

#### Main App Screens

The main app uses a **right-side drawer navigator** (hamburger menu) with these items: Home, Community, Nora Assistant, Bonuses, Results, Session History, Leaderboard, Profile, Settings, Subscription, Logout.

**Home Screen** (Main Dashboard)

- What users see: Daily motivational quote (from 200+ quote database), quick action buttons ("Start Focus Session," "View Profile"), trail buddy animation, settings and leaderboard access icons
- What happens: This is the hub — users start study sessions from here, see their buddy, and access all major features
- Details: Interactive walkthrough highlights key areas for first-time users; pulse animations on the focus button; reanimated entrance animations

**Community Screen** (Social Hub)

- What users see: Three tabs at the top — **Friends**, **Messages**, **Study Rooms**
- **Friends tab:** Friend request notifications with accept/decline buttons, scrollable friend list with online status
- **Messages tab:** Conversation list showing recent chats, unread indicators, timestamps

### 8.4 AI Companion: Nora (Deep Dive)

Nora is HikeWise's flagship AI feature, exclusive to Elite subscribers. She's not a generic chatbot — she's a **personalized AI study coach** that learns about each student over time.

**Technical implementation:**

- Powered by **OpenAI Responses API** with native tool use
- **Voice interaction** via Whisper AI transcription (students can talk to Nora)
- **PDF analysis** via file_search tool (upload textbooks, Nora explains concepts)
- **Code interpreter** for math and science calculations
- **Web search** for real-time research assistance
- **Conversation continuity** using `previous_response_id` chaining (multi-turn context)

**Long-term memory system:**
Nora extracts and stores facts about each student in 5 categories:
| Category | Examples |
|----------|---------|
| Academic | Weak subjects, strengths, current courses |
| Preference | Preferred study times, learning style, session length |
| Struggle | Procrastination patterns, attention difficulties |
| Goal | Learning objectives, GPA targets, exam dates |
| Personal | Background info relevant to coaching |

Each memory has a confidence score and is updated as Nora learns more. This means Nora gets better the more a student uses her.

**Chat UI:**

- ChatGPT-style threaded conversations with session history in a side panel
- Floating voice recording panel for voice-first interaction
- Markdown rendering for formatted responses (code blocks, lists, bold)
- Deep think toggle for research-mode responses
- Quick action suggestions at the bottom
- Gradient shimmer loading animation while Nora processes
- PDF attachment support from the E-Book library

**Rate limits by tier:**
| Tier | Messages per day |
|------|-----------------|
| Free | 5 |
| Basic | 15 |
| Pro | 50 |
| Elite | Unlimited |

**Patrick AI** — A secondary, simpler AI chat companion available to Basic+ tiers. Patrick provides motivational support and basic study tips without the advanced tools (no PDF analysis, no memory system, no voice).

### 8.7 Design System & Premium UI

The app's visual identity prioritizes premium feel, smooth animations, and haptic feedback at every touchpoint.

**Animation System:**

- All UI animations use **React Native Reanimated v2** running on the UI thread for 60fps performance
- **Spring physics** for interactive feedback (5 presets: quick, standard, bouncy, gentle, snappy)
- **Timing presets:** instant (100ms), fast (200ms), normal (300ms), slow (500ms)
- **Stagger delays:** fast (50ms), normal (80ms), slow (120ms) for list entrances
- **Easing curves:** easeOut, easeIn, easeInOut, bounce

**Animation hooks (reusable across screens):**

- `useCounterAnimation` — Animated number counting (for stats, scores)
- `useFloatingAnimation` — Gentle hovering effect (for buddy, cards)
- `usePulseAnimation` — Pulsing glow (for focus button, notifications)
- `useButtonPressAnimation` — Press feedback with spring bounce
- `useEntranceAnimation` — Fade + slide for screen transitions
- `useSuccessAnimation` — Celebratory burst for achievements

**Premium UI Components:**
| Component | Description |
|-----------|------------|
| `LiquidGlassCard` | Apple-style frosted glass card with blur effect |
| `HolographicBadge` | Achievement badge with multi-color holographic glow, rarity-based |
| `StatOrb` | Interactive gradient stat display orb |
| `ProductivityScoreRing` | Circular progress ring with tier-based color |
| `AnimatedButton` | Spring-based button with haptic feedback |
| `StaggeredItem` / `StaggeredList` | Entrance animations with configurable stagger delays |
| `ShimmerLoader` | Skeleton loading states (text, card, avatar, stats grid variants) |

**Theme System:**
6 color themes available (tier-gated):

- **Office** (default/Basic) — Professional neutrals
- **Forest** — Natural greens (brand-aligned)
- **Neon** — Vibrant cyberpunk palette
- **Ocean** — Cool blues and teals
- **Royal** — Deep purples and golds
- **Sunset** — Warm oranges and reds

Dark mode toggle available across all themes.

**Haptic Patterns:**

- `buttonPress` — Light tap on button interactions
- `success` — Medium impact for completed actions
- `error` — Warning haptic for errors
- `selection` — Subtle tick for option changes
- `milestone` — Strong impact for achievement unlocks

**Typography Scale:**
Display, H1, H2, H3, Body, Caption, Label, Stat — all with consistent spacing and weight definitions. Tabular number variants for statistics and timers.
